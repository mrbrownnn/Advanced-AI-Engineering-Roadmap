# Graduation Incidents

_Graduation-level diagnostic scenarios will be developed alongside the capstone._

These scenarios differ from module-level incidents:

- **Multiple interacting systems** — not isolated to a single component
- **Ambiguous symptoms** — symptoms could have multiple root causes across different layers
- **Competing constraints** — SLO, budget, security, and quality cannot all be fully satisfied
- **Incomplete information** — the learner must identify what data they need and acquire it
- **No single right answer** — the assessment is the quality of reasoning, not the conclusion
