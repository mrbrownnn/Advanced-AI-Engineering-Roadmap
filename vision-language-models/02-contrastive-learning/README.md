# 02 — Contrastive Learning

## Purpose

Understand how multimodal contrastive objectives align image and text representations into a shared semantic embedding space.

## Topics

- Contrastive objectives: InfoNCE loss, positive and negative pairs
- CLIP (Contrastive Language-Image Pre-training) architecture and dual encoders
- SigLIP: sigmoid loss for language-image pre-training
- Batch size dependency in contrastive learning
- Zero-shot classification and cross-modal retrieval mechanics

## Key Questions

- How does contrastive learning align two fundamentally different modalities?
- Why does standard contrastive learning require very large batch sizes?
- What are the limitations of dual-encoder contrastive models compared to generative VLMs?
