## Priority Levels

- **MUST** — Core to understanding the module. Cannot be skipped.
- **SHOULD** — Important context. Read if time allows.
- **OPTIONAL** — Depth or breadth extension. For stretch learners.

## Rules

- Use only real, verifiable references
- Prefer original papers and official technical reports
- If uncertain about any bibliographic data, add `TODO: VERIFY REFERENCE`
- Never invent titles, authors, URLs, or publication years
