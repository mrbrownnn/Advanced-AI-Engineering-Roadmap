# Speech AI Track Roadmap

This track is designed to be completed during Month 3 of the program, alongside core Modules 06–08.

| Week | Module | Focus |
|------|--------|-------|
| 9 | [01 — Audio Representation](01-audio-representation/) | Waveforms, STFT, spectrograms, mel features |
| 10 | [02 — Speech-to-Text](02-speech-to-text/) | ASR architectures, Whisper, streaming, diarization |
| 11 | [03 — Text-to-Speech](03-text-to-speech/) | TTS pipeline, neural vocoders, diffusion/flow TTS |
| 11 | [04 — Streaming Speech](04-streaming-speech/) | Real-time ASR/TTS, chunk buffering, RTF |
| 12 | [05 — Speech Evaluation](05-speech-evaluation/) | WER, CER, MOS, latency metrics |
| 12 | [06 — Voice Agent Systems](06-voice-agent-systems/) | STT → LLM → TTS pipeline, turn latency |

## Pacing

- ~1–2 modules per week, alongside core track work
- Focus on audio representation and voice agent systems engineering
- Understand real-time latency constraints and streaming pipelines
