# Generative Media Track Roadmap

This track is designed to be completed during Month 4 of the program, alongside core Modules 09–11.

| Week | Module | Focus |
|------|--------|-------|
| 13 | [01 — Generative Model Foundations](01-generative-model-foundations/) | VAE, GAN (historical), latent variables |
| 13 | [02 — Diffusion](02-diffusion/) | DDPM, denoising score matching, noise schedules |
| 14 | [03 — Latent Diffusion](03-latent-diffusion/) | Stable Diffusion, latent space generation |
| 14 | [04 — Diffusion Transformers](04-diffusion-transformers/) | DiT, scaling transformers for generation |
| 15 | [05 — Flow Matching](05-flow-matching/) | Continuous normalizing flows, flow matching |
| 15 | [06 — Image Generation](06-image-generation/) | Conditioning, guidance (CFG), controlability |
| 16 | [07 — Video Generation](07-video-generation/) | Temporal modeling, 3D attention, video diffusion |

## Pacing

- ~1–2 modules per week, alongside core track work
- Focus on understanding architecture evolution (VAE → Diffusion → DiT → Flow Matching)
- Emphasize serving costs, sampling steps, and memory footprint
